Onboard an investor

Creates the login, the risk profile, the portfolio account and a bank account. These are four separate calls with no shared transaction, so each result is reported individually.

Risk level

The investor is assigned to you as their manager, and starts with KYC status PENDING. A bank account is opened for them automatically - bank name, IFSC and account number are all generated, so you only need to set an opening deposit if you want one.
